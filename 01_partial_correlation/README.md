# 偏秩相关

分析单位为环境坐标组。个体原始 SV 按组累加实测 ALT 拷贝数与实测倍性，计算组频率。对每个位点与每个环境因子分别排秩，投影去除显式 SV PC 和可选经纬度，检验两组残差的相关性。每个环境、每个 PC 规格内，在有效位点上做 BH。

`python3 run.py 3 PREPARED OUTPUT`。相同命令支持 5、10。共享准备步骤提供全部组均可估的频率列。也可使用 `--frequency` 传入行顺序相同、第一列为 `id` 的 TSV 或 TSV.GZ，纳入部分组缺失的位点。脚本逐缺失模式评估有效组数、自由度和可检验性。

`historical_main405_summary.tsv` 记录 2026-11-18 的历史分析，包含其他协变量口径和逐位点可用组设计。历史 P 值与使用新共享准备输入得到的结果应分别追溯。
